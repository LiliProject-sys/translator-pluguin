Orange翻译

安装与更新说明

当前版本：v1.0.4

本说明适用于 Chrome 和 Microsoft Edge。首次安装请选择“首次安装”；已经安装过旧版本请选择“更新已有版本”。

开始前准备

  1. 下载收到的 ZIP 测试包。
  2. 将 ZIP 完整解压。
  3. 不要直接在压缩包预览窗口里加载插件。
  4. 建议将解压后的文件夹放到一个不会随意移动或删除的位置。
  5. 加载插件时，需要选择的是能直接看到 manifest.json 的文件夹。
  6. 测试访问码由开发者另行发送，本说明中不包含访问码。
安装后不要删除或移动插件文件夹。浏览器加载的是这个本地文件夹，文件夹被删除或移动后，插件可能无法继续使用。

Chrome：首次安装

  1. 打开 Chrome。
  2. 在地址栏输入 chrome://extensions 并回车。
  3. 打开右上角“开发者模式”。
  4. 点击“加载已解压的扩展程序”。
  5. 选择解压后的插件文件夹。
  6. 确认选择的文件夹中能直接看到 manifest.json。
  7. 安装成功后，扩展列表中应出现 Orange翻译。
  8. 点击浏览器右上角扩展按钮，将 Orange翻译 固定到工具栏。
  9. 打开 Orange翻译 的设置页。
  10. 输入开发者另行发送的测试访问码。
  11. 点击验证。
  12. 页面显示“已连接，可以开始使用”后即可使用。
  13. 打开普通英文网页，划选英文测试。
不要选择 ZIP 文件本身。不要选择只包含另一个文件夹的最外层目录。

Microsoft Edge：首次安装

  1. 打开 Microsoft Edge。
  2. 在地址栏输入 edge://extensions 并回车。
  3. 打开左侧或页面中的“开发人员模式”。
  4. 点击“加载解压缩的扩展”。
  5. 选择解压后的插件文件夹。
  6. 确认选择的文件夹中能直接看到 manifest.json。
  7. 安装成功后，确认扩展名称为 Orange翻译。
  8. 将扩展固定到工具栏。
  9. 打开设置页。
  10. 输入开发者另行发送的测试访问码。
  11. 验证成功后，在普通英文网页中划词测试。
不同版本的 Edge 中，按钮名称可能略有不同。

已经安装过 Orange翻译：推荐更新方法

推荐在原来的插件文件夹中替换文件，然后点击“重新加载”。这样更容易保留原来的扩展身份、设置和已保存数据。

  1. 找到之前安装 Orange翻译 时使用的本地插件文件夹。
  2. 下载并解压新的测试包。
  3. 打开新包中能直接看到 manifest.json 的目录。
  4. 将新版本目录中的全部插件文件复制到旧插件文件夹。
  5. 选择覆盖同名文件。
  6. 不要把整个新文件夹再套进旧文件夹里。
  7. 打开扩展管理页：Chrome 使用 chrome://extensions，Edge 使用 edge://extensions。
  8. 找到 Orange翻译。
  9. 点击扩展卡片上的“重新加载”按钮。
  10. 确认扩展显示的新版本号与本页顶部一致。
  11. 打开设置页，确认仍显示“已连接”。
  12. 测试划词、自动翻译开关、生词本和浮窗拖动。
推荐保持原来的插件文件夹路径不变。直接加载另一个新文件夹，浏览器可能把它识别为另一份扩展，从而出现重复插件，原来的设置或生词本也可能不会自动带过去。

更新失败时：重新安装

这个方法更彻底，但可能需要重新输入访问码。优先尝试“覆盖旧文件夹并重新加载”的更新方法。

  1. 先记住或重新向开发者获取测试访问码。
  2. 在扩展管理页移除旧版 Orange翻译。
  3. 解压最新测试包。
  4. 按“首次安装”步骤加载新目录。
  5. 重新输入测试访问码并验证。
  6. 重新测试插件。
重新安装可能不会保留旧版的本地设置和生词本数据。

安装或更新后如何确认成功

  • 扩展名称显示为 Orange翻译。
  • 版本号与本页顶部一致。
  • 图标为蓝底橙子切片。
  • 设置页显示“已连接，可以开始使用”。
  • Popup 中显示“当前已开启”或“当前已关闭”。
  • 开启状态为橙色强调。
  • 英文单词可以划词解析。
  • 英文短语、标题和整句可以整体翻译。
  • 中文选区不会自动触发。
  • 浮窗顶部标题区域可以拖动。
  • 浮窗正文仍可选择和复制。
  • 生词可以加入生词本。

常见问题

1. 提示“清单文件缺失或无法读取”

通常是选错了文件夹。请进入下一层，选择能直接看到 manifest.json 的文件夹。

2. 更新后名称、图标或版本没有变化

  • 在扩展管理页点击“重新加载”。
  • 关闭并重新打开扩展管理页。
  • 取消固定后重新固定。
  • 必要时重启浏览器。
  • 确认覆盖的是原来浏览器加载的那个文件夹。

3. 插件显示错误或自动停用

  • 检查插件文件夹是否被移动。
  • 检查插件文件夹是否被删除。
  • 确认文件已经解压，不是仍在压缩包内。
  • 确认没有选择错误目录。

4. 页面显示未连接

  • 打开设置页。
  • 重新输入测试访问码。
  • 点击验证。
  • 测试访问码失效时，联系开发者获取新访问码。

5. 划词没有反应

  • 检查 Popup 中是否为“当前已开启”。
  • 尝试刷新当前网页。
  • 浏览器内部页面不支持。
  • 网页 PDF、本地 PDF 暂不支持。
  • Edge F9 阅读模式暂不支持。
  • 中文选区不会触发翻译。
  • 普通英文网页应可正常使用。

6. 更新后出现两个 Orange翻译

这是因为加载了新的文件夹，而旧版仍然保留。先通过版本号区分新旧版本，确认新版本可用后，可以在扩展管理页移除旧版本。

基础使用说明

  1. 打开普通英文网页。
  2. 用鼠标选中英文。
  3. 等待浮窗显示翻译。
  4. 单个词会显示单词解析。
  5. 多词短语、标题、句子和段落会整体翻译。
  6. 拖动浮窗顶部标题区域可以移动浮窗。
  7. 点击“加入生词本”保存。
  8. 在 Popup 中控制划词自动翻译开关。

本页面可离线打开，不包含测试访问码或任何密钥。
