Translator-plugin Cloud Run Beta 使用说明

当前是小范围 Beta 测试版。插件版本：1.0.1。测试包日期：2026-07-23。

支持桌面版 Google Chrome 与 Microsoft Edge。不支持手机浏览器；不承诺 Firefox 或 Safari 兼容。

安装前准备

  • 请先完整解压 ZIP，不能直接从压缩包里加载扩展。
  • 测试访问码由开发者单独发送，请不要公开或转发。
  • 不需要安装 Python，不需要启动本地 Gateway，也不需要准备 Gemini API Key。
  • 如果电脑里已有旧测试版，建议先禁用或移除，避免两个版本混淆。

Google Chrome 安装步骤

  1. 解压 ZIP。
  2. 在地址栏输入 chrome://extensions。
  3. 打开右上角“开发者模式”。
  4. 点击“加载已解压的扩展程序”。
  5. 选择解压后、根目录直接包含 manifest.json 的文件夹。
  6. 打开插件设置页。
  7. 输入单独收到的测试访问码。
  8. 点击“验证并开始使用”。
  9. 在普通英文网页中划选单词或句子测试。

Chrome 可能显示开发者模式扩展提醒，这是测试版的正常现象。不要选择 ZIP 文件本身，也不要只选择外层错误目录。

Microsoft Edge 安装步骤

  1. 解压 ZIP。
  2. 在地址栏输入 edge://extensions。
  3. 打开“开发人员模式”。
  4. 点击“加载解压缩的扩展”。
  5. 选择直接包含 manifest.json 的文件夹。
  6. 打开设置页。
  7. 输入测试访问码并验证。
  8. 在普通英文网页中划词测试。

Edge 的按钮文案可能因版本略有差异，含义通常是“加载解压缩的扩展”。

基本使用

  • 选中单词：显示词形、音标、词性、语境含义。
  • 可查看详细解释或近义词区别。
  • 选中句子：显示整句翻译。
  • 点击“加入生词本”保存。
  • 生词的语境译文可能稍后异步补写。
  • 设置页中普通测试用户应保持 Gateway Beta。
  • “Gemini AI 语境解析”等高级 Provider 属于自带 API Key 模式，朋友测试时不要切换。

如何确认连接成功

  • 设置页显示“已连接，可以开始使用”。
  • 当前启用显示 Gateway Beta。
  • 普通英文网页划词后能返回结果。
  • 首次请求可能因 Cloud Run 冷启动略慢。
  • 用户无需保持开发者电脑开机。

常见问题

找不到“加载已解压”按钮

请确认已经打开 Chrome 的“开发者模式”或 Edge 的“开发人员模式”。

选择文件夹后提示 manifest 缺失

请选择根目录直接包含 manifest.json 的文件夹，不要选择 ZIP，也不要选择多套一层的外层目录。

输入测试访问码后提示无效

请确认访问码完整复制，没有多余空格。访问码无效或过期时需要联系开发者重新确认。

一直显示正在处理

首次请求可能稍慢。若持续失败，请记录时间、浏览器、操作步骤和截图后反馈。

Chrome/Edge 重启后插件不见了

开发者模式加载的扩展依赖原解压目录。请不要删除或移动该目录；如已移动，请重新加载已解压扩展。

页面划词没有反应

请先在普通英文网页测试。chrome://、edge://、扩展商店等浏览器内部页面无法运行内容脚本。

同时安装旧版和新版导致混淆

建议只保留一个 Translator-plugin 测试版。先禁用或移除旧测试版，再加载新的解压目录。

如何更新到新的测试包

先禁用或移除旧测试版，解压新的 ZIP 到新目录，再重新“加载已解压”。不要覆盖旧目录后继续引用已删除的路径。

如何卸载

Chrome 打开 chrome://extensions，Edge 打开 edge://extensions，找到 Translator-plugin 后点击移除。

隐私与安全说明

  • 划选的单词或句子和必要上下文会发送到远程 Gateway，再由 Gateway 调用 Gemini。
  • 可选页面标题可能随请求发送。
  • 不发送 Cookie、浏览历史、完整网页、pageUrl、全量生词本或本地 API Key。
  • 共享测试访问码保存在浏览器扩展本地存储中，并通过 Authorization Header 发送。
  • Gemini API Key 不在插件包中，而保存在服务端。
  • 不要把测试访问码转发给无关人员。
  • 当前是 Beta，遇到敏感网页时不要划选不希望发送的私人内容。

  • 问题发生的大概时间。
  • 问题属于 Token 验证、单词解析、详细解释、整句翻译还是生词保存。
  • 错误截图。截图中请不要暴露测试访问码或私人网页内容。
