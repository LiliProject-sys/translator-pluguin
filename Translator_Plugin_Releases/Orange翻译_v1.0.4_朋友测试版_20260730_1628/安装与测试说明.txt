Orange翻译 Beta 测试版安装与测试说明

一、安装前

1. 请先完整解压这个 ZIP，不要直接在压缩包里加载扩展。
2. 测试访问码会由开发者单独发送，请不要公开或转发。
3. 不需要安装 Python，不需要启动本地 Gateway，也不需要准备 Gemini API Key。
4. 如果电脑里已经装过旧测试版，建议先在扩展管理页禁用或移除旧版，避免混淆。

二、Chrome 安装

1. 打开 Chrome。
2. 在地址栏输入 chrome://extensions 并回车。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后、能直接看到 manifest.json 的文件夹。
6. 建议把 Orange翻译 固定到工具栏。

三、Edge 安装

1. 打开 Edge。
2. 在地址栏输入 edge://extensions 并回车。
3. 打开“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择解压后、能直接看到 manifest.json 的文件夹。
6. 建议把 Orange翻译 固定到工具栏。

四、首次配置

1. 打开 Orange翻译 的设置页。
2. 输入开发者单独发给你的测试访问码。
3. 点击“验证并开始使用”。
4. 看到“已连接，可以开始使用”后，就可以在普通英文网页中划词测试。
5. 测试访问码不要写进截图或发给其他人。

五、建议测试

1. 英文单词：例如 employed、robust、challenging。
2. 多词短语或短标题：例如 machine learning、Definition of LLM Agent。
3. 英文整句：选择完整英文句子，查看整体翻译。
4. 长段落：选择 Abstract 里的一小段，观察等待时间和结果。
5. 自动翻译开关：在 Popup 里切换“当前已开启 / 当前已关闭”。
6. 加入生词本：保存词条后打开生词本查看。
7. 浮窗拖动：按住浮窗顶部原文标题区域拖动，继续划词确认位置保持。
8. 浮窗 resize：拖动浮窗右下角调整大小。

六、已知限制

1. chrome://、edge://、扩展商店等浏览器内部页面不支持。
2. 网页 PDF 和本地 PDF 暂不支持。
3. Edge F9 阅读模式暂不支持。
4. 扫描图片、Canvas 文本和复杂阅读器中的文字可能无法正常划选。
5. 首次请求可能因为远程服务冷启动稍慢。

七、反馈问题时请提供

1. 浏览器名称和版本。
2. 测试网页。
3. 选中的英文原文。
4. 实际结果和大概等待时间。
5. 截图。截图里请不要包含测试访问码、私人网页内容或账号信息。
