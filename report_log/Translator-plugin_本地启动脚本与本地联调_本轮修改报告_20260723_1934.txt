脚本能力：
- 使用 $PSScriptRoot 定位 gateway 目录，并推导项目根目录；
- 检查 gateway/.venv/Scripts/python.exe 是否存在；
- 检查 gateway/.env 是否存在；
- 检查 BETA_ACCESS_TOKEN、GEMINI_API_KEY、GEMINI_MODEL 是否存在且非空；
- 不打印 Token 或 Gemini API Key；
- 固定使用 http://127.0.0.1:8000；
- 启动命令为 python -m uvicorn gateway.app.main:app --host 127.0.0.1 --port 8000 --env-file gateway/.env；
- 前台运行，Ctrl+C 可停止；
- 如果 /health 已返回 translator-gateway，则提示本地 Gateway 已运行并退出 0；
- 如果 8000 端口上是其他服务，则受控报错，不尝试杀进程。

→ 脚本检查 gateway/.venv、gateway/.env 和必需环境变量
