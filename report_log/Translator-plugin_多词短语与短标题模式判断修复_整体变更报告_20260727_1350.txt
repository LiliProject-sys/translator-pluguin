2. 修改前行为

旧规则位于 content.js 的 detectSelectionRequestType(selectedText)。
旧规则依赖：
- 是否包含 . ? ! ;
- wordCount > 10
- text.length > 80

因此短标题和短语会被误判：
- Definition of LLM Agent 没有句末标点、词数不超过 10、长度不超过 80，旧规则会进入 wordAnalysis。
- A Roadmap of Agent Research and Development 同样容易进入 wordAnalysis。
- machine learning、Security and Privacy、in terms of 等多词文本也可能被当成单词分析。

问题来源说明：
这是原有 detectSelectionRequestType() 启发式中的边界问题，在自动翻译开关与中文过滤功能完成后的人工测试中被发现。
目前没有证据表明它是自动翻译开关或中文过滤引入的回归。中文过滤和开关发生在模式判断之前；纯英文短标题不会触发中文过滤。

3. 修改后行为

新规则冻结为“内部空白”判断：
- selectedText trim 后为空：保持外层安全行为，函数返回 wordAnalysis，不发送无效请求由外层控制。
- trim 后没有内部空白：wordAnalysis。
- trim 后存在至少一个内部空白：sentenceTranslation。

连续词项示例：
- roadmap -> wordAnalysis
- roadmap. -> wordAnalysis
- state-of-the-art -> wordAnalysis
- state‑of‑the‑art -> wordAnalysis
- don't / don’t / user's -> wordAnalysis
- GPT-4 / LLM-based / agent-based -> wordAnalysis

多词文本示例：
- machine learning -> sentenceTranslation
- machine    learning -> sentenceTranslation
- machine\tlearning -> sentenceTranslation
- machine\nlearning -> sentenceTranslation
- machine\u00A0learning -> sentenceTranslation
- Definition of LLM Agent -> sentenceTranslation
- A Roadmap of Agent Research and Development -> sentenceTranslation
- Security and Privacy -> sentenceTranslation

sentenceTranslation 的 requestType 名称保持不变，但产品语义现在承载短语、固定搭配、标题、句子和段落的整体翻译。
