2. 本轮完成了什么

本轮把 Translator-plugin 从“用户自己选择 Provider 并填写 API Key”的纯客户端模式，扩展出一个本地 Gateway Beta 模式。普通用户现在可以在 options 页面顶部输入共享测试访问码，验证成功后自动切换到 provider=gateway；插件请求本地 http://127.0.0.1:8000 Gateway，由服务端固定 Skill 调用 Gemini。

内部主要变化：
- 新增 gateway/ FastAPI 服务端；
- 新增 gateway-language-provider.js；
- translation-provider.js 注册 gateway；
- background.js 复用 TEST_LANGUAGE_PROVIDER 验证候选 Token；
- options 页面新增欢迎区和 Token 验证流程；
- manifest 增加 http://127.0.0.1:8000/*；
- 新增共享 JSON 合同 fixture 和 Gateway 测试。

明确没有修改：
- content.js 主链路；
- vocabularyEntries 数据结构；
- 旧 Baidu/Gemini/DeepSeek/Mock Provider 的核心逻辑；
- manifest 版本号，仍为 1.0.1；
- Cloud Run 实际部署。

4. 接口、调用链和数据变化

新增 HTTP 路由：
- GET /health：无需 Authorization，不调用 Gemini，不需要 requestId，返回 { status: "ok", service: "translator-gateway" }。
- POST /v1/auth/verify：Authorization: Bearer <候选Token>，不调用 Gemini，不需要 requestId，成功返回 { status: "ok", access: "granted" }，失败返回 INVALID_ACCESS_TOKEN。
- POST /v1/language：Authorization: Bearer <共享Token>，必须 requestId，调用固定 Gemini 模型 gemini-3.1-flash-lite，返回 { status, requestId, data } Envelope。

GatewayProvider 发送字段白名单：
- requestId
- requestType
- analysisMode
- sourceLanguage
- targetLanguage
- text
- contextSentence
- pageTitle

明确不发送：
- userQuestion
- Prompt
- Skill 内容
- 模型名
- providerPreference
- Gateway URL
- Gemini API Key
- pageUrl
- hostname
- 页面正文
- vocabularyEntries 全量

新增 storage 字段：
- translationSettings.gatewayAccessToken
- translationSettings.provider 可为 gateway

调用链修改后：
用户划词
→ content.js
→ background.js
→ languageService.process()
→ translation-provider.js providerRegistry.gateway
→ gateway-language-provider.js
→ FastAPI /v1/language
→ Gemini
→ FastAPI Schema 校验
→ GatewayProvider 校验 requestId
→ normalizeProviderResult()
→ background.js 添加最终 status
→ content.js 渲染

status 边界：
- Gateway HTTP 响应有外层 status；
- GatewayProvider 只取 response.data，合并 requestId；
- background.js 继续返回插件已有 status；
- 不产生双层 status。

取消链路：
CANCEL_LANGUAGE_REQUEST
→ languageService.cancelRequests(requestIds)
→ gatewayProvider.cancelRequest(requestId)
→ controller.abort()
→ AbortError 映射为 REQUEST_CANCELLED
→ background.js 返回 status: "cancelled"

输入限制：
- text：trim 后必填，最大 5000 字符；
- contextSentence：最大 5000 字符；
- pageTitle：最大 300 字符；
- 请求体最大 32 KB；
- Gateway Token 使用 hmac.compare_digest。
