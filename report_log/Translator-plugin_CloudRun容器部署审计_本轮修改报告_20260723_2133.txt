3. Dockerfile 修改前 → 修改后

修改前：
- Dockerfile 假定 build context 是仓库根目录；
- 使用 COPY gateway/requirements.txt 与 COPY gateway ./gateway；
- 启动模块为 gateway.app.main:app；
- 当 Cloud Run Source Deploy 从 gateway/ 目录执行时，上述 COPY 路径不成立。

修改后：
- Dockerfile 以 gateway/ 作为 build context；
- 使用 COPY requirements.txt ./requirements.txt；
- 使用 COPY app ./app；
- 容器内应用目录为 /app/app/main.py；
- 启动模块为 app.main:app；
- CMD 使用 exec uvicorn app.main:app --host 0.0.0.0 --port ${PORT:-8080}；
- 容器不复制 .env，不固定 127.0.0.1 或本地 8000。
