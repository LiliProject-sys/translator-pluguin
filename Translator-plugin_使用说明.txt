Translator-plugin 使用说明

版本：v1.0.0 稳定体验版

一、插件安装

1. 解压收到的插件压缩包。

不要删除解压后的文件夹，Chrome 加载的是该文件夹本身。

2. 打开 Chrome 扩展管理页面：

chrome://extensions/

3. 打开右上角“开发者模式”。

4. 点击“加载已解压的扩展程序”。

5. 选择包含 manifest.json 的 Translator-plugin 项目根目录。

成功后即可在 Chrome 工具栏看到 Translator-plugin。

二、配置 Provider

点击插件图标，在 popup 中点击“设置”。

当前支持：

- Gemini AI 语境解析；
- DeepSeek AI 语境解析；
- 百度快速翻译；
- Mock 测试模式。

如果只是体验测试，可以先使用提供的 API Key。API Key 属于个人访问凭证，不要公开传播。

三、申请 Gemini API Key

如果需要自己的 Gemini API Key：

1. 打开 Google AI Studio：

https://aistudio.google.com/

2. 登录 Google 账号。

3. 创建 API Key。

4. 复制生成的 Key。

5. 回到插件设置页，选择“Gemini AI 语境解析”。

6. 填写 Gemini API Key，保存后点击“测试 Gemini”。

四、基本使用

1. 打开普通英文网页或论文网页。

2. 划选英文单词或短语。

插件会自动显示浮窗，提供：

- 单词原形；
- 音标；
- 词性；
- 简短含义；
- 当前句中含义；
- 必要时提供一个近义词核心区别。

3. 划选完整句子或较长段落。

插件会进入句子/段落翻译模式，显示自然中文译文，并在必要时补充一个关键术语解释。

4. 点击“加入生词本”。

词条会保存到当前 Chrome 的本地扩展存储中。

5. 点击插件图标，再点击“打开生词本”。

独立生词本页面支持：

- 查看词条；
- 搜索；
- 随机、最近、字母排序；
- 删除；
- 打开来源；
- 查看英文语境和中文语境译文；
- 在英文语境中高亮当时查询的词。

五、当前限制

- Chrome 内置 PDF Viewer 当前不支持无缝划词。
- WPS PDF 插件仍属于下一阶段可行性验证。
- 不支持 Windows 全系统全局划词。
- AI 输出可能存在误差。
- Provider 能力依赖网络、API Key、配额和服务状态。
- 生词本当前连续下拉渲染，没有传统分页。
- 旧词条不会在打开生词本时自动批量补译。
- 句子边界仍是启发式规则，不是完整 NLP 解析。

六、隐私与本地数据

- API Key 保存在当前 Chrome 的 chrome.storage.local 中。
- 生词数据 vocabularyEntries 也保存在当前 Chrome 本地。
- 不要把自己的 API Key、Token、Cookie 或真实生词导出文件提交到 Git 仓库。

七、问题反馈建议

反馈时请提供：

1. 使用的网站或论文；
2. 选择的单词、短语或句子；
3. 期望结果和实际结果；
4. 截图；
5. 如方便，可提供 Chrome 扩展 Service Worker Console 中的错误信息。

当前 Chrome 版核心功能已基本完善，适合真实用户日常使用和收集反馈。后续重点方向是 WPS PDF 无缝划词可行性验证，以及根据真实使用反馈继续优化。
